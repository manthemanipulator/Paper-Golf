# ⛳ Paper Golf — Version 2026.7.21: Random Leaderboard Toggle

## 🆕 What's New

**Daily / Weekly / Monthly Leaderboard Toggle:** The Random mode leaderboard now has a toggle so you can view the top scores for today, this week, or the whole month — not just the monthly view. Still capped at the top 10, just more ways to see where you stack up.

## 🐛 Bug Fix

The Daily leaderboard could fail to load after the last update — a leftover bug from the stats display fix in 2026.7.20. It's fixed now.

## 🔧 Also in This Release

A few small spacing tweaks to the leaderboard/scorecard popup so it fits better on smaller screens.
